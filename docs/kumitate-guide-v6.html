巡る天の心臓 — 組み立ての書

哲学はひとつ:「各段で必ず動く」。動かないまま次へ進まない

はじめる前に

印刷: stl_v6/ 全38ファイル (Phrozen Sonic Mini 4K・タフレジン)。プリンタは長期休眠明け → 復活チェックリスト (nFEP膜・LCD露光・Z軸・レジン新調) を先に。
道具: 瞬間接着剤 / 紙 (シム用) / ピンバイス (穴さらい) / ニッパ・ヤスリ / 真鍮φ3棒 60mm・27.4mm・9.9mm の3本 / (電動にする時) M3 ローレットねじ×8mm ×2・M3 皿小ねじ×8mm+ナット ×2
心構え: 圧入がきつい時は無理せず穴をさらう。渋い噛み合いは「歯当たり調整」(BOM末尾) が織り込み済み

全部品の分解図 (手回しの姿) — 印刷部品47個と真鍮軸3本

Stage 0 「土台を継ぎ、三脚で立たせる」

部品: base_seg0/1/2 (×3)・splice_plate (×3)・tripod_leg (×3)・foot_ring_seg0/1/2/3
  1. 3枚のセグを平面で突き合わせる (切り線 az48/168/288 — 裏スタッドの向きで判別)
  2. 境界の上面 r23.4〜29.4 帯 (浅皿の外・土手の内) に splice_plate を瞬着 ×3ヶ所
  3. 裏返して隠し刻印「ΜΗΧΑΝΗ ΟΥΡΑΝΟΥ」を眺めてニヤリとする (必須工程)
  4. 足輪: foot_ring_seg×4 を平らな机の上で継ぐ (切り口のダボ d1.6 を隣の穴へ差して瞬着)
  5. ベースを裏返したまま、縁の小穴3つ (刻印のさらに外側) に tripod_leg×3 の上ピンを差して瞬着 — 脚は外へ反る向き
  6. 上を向いた脚の下ピン3本に足輪を載せて瞬着 (目盛りが抜けている3ヶ所が脚の位置) → そっと起こす
✅ 動作確認: 足輪で机に立ってガタつかない・浅皿と土手の円が真円に繋がっている・ベースの下 (高さ48mm) に指が入る

Stage 1 「地下と背骨」

部品: ub_w1p1 (×2)・ub_pinionA・ub_w3・ub_lantern・spine・planet_gear (×2)・stud_cap (×2)・sun_gear・ring46・hand_knob・真鍮27.4mm+9.9mm
  1. 裏側: W1P1・W2P2 を吊りスタッドへ (P面が下向き=ベースから遠い側) → スタッド端に軸端キャップを瞬着 (抜け落ち防止)
  2. 縦シャフト9.9mmの下端に ub_w3 を圧入 → ベース穴 (r24.5) へ下から通す
  3. 表に出た上端へ ub_lantern を圧入・ピン1本が機械中心を向く角度で瞬着 (LNT_PHクロッキング)
  4. spine (背骨) をそっと浅皿へ — 冠環43Tが提灯ピンと噛む
  5. 遊星2個をスタッドに載せ stud_cap を瞬着。中心軸27.4mm (下端8mm をヤスリで D カット) を通し、裏から ub_pinionA・表の z9 に sun_gear を圧入
  6. ring46 を土手に載せる (下面の溝が土手の上に乗る)
  7. ベースの下から、中心軸の下端 (D カット) に hand_knob を差す (軽圧入・抜き差しできる)
✅ 動作確認: 裏ノブを回す → リングが軽く回り、ターンテーブルがごくゆっくり逆方向に回れば地下開通 (リング約230回転でターンテーブル1周 — 少し回して冠環の歯が1枚動けば正常)
渋い時: 地下輪列は遊び大きめ設計。逆に飛ぶ/滑る時は吊りスタッド接着前に軸間へ紙シムを入れて詰める

Stage 2 「心臓が動く」

部品: cage_core・bevel_sun・inner_frame・moon_globe・ret_gear・e2p・stud_cap・真鍮60mm
  1. cage_core を背骨のボスへ (雷文の面が上・下面の冠歯24がリング上面のピン24と噛む)
  2. bevel_sun をボス頂部の段に圧入・瞬着 (回らない部品)
  3. inner_frame を第2軸位置へ。真鍮60mmを −x腕 → 月球 → フレームハブ → G (ret_gear) → E1スリーブ → +x腕 の順で通す
  4. 月球 (クレーター上向き基準) と G を瞬着。e2p をスタッドに載せキャップ瞬着
✅ 動作確認: ノブを回す → 12°傾いた心臓が回り、月の額縁が縦に回り、月が公転ごとに1回うなずけば成功。ゆっくり回し続けると傾きの向きも徐々に変わる (歳差)

Stage 3 「大周期を刻む」

部品: saros_idler・saros_seg0/1/2・crown_idler・st1_carrier・ring_seg0/1/2・horizon_seg0/1/2
  1. saros_seg×3 をダボ接合し、ベースの座溝へ落とす → saros_idler を上からスタッドへ (提灯ピンを環の歯間へ・22T をリング46に噛ませる)。順番注意: 中間輪が先だと円盤が環の歯にかぶって環が入らない
  2. crown_idler (22T を下に) をスタッドへ・st1_carrier を腕木のスタッドへ — どちらも肩の上に載る
  3. ring_seg×3 をダボ接合 → 支柱ピン2本を下面溝に、内縁下面を方位20°の座へ (3点とも天面がリングの傾きに合わせてあるので、そのまま載る)
  4. horizon_seg×3 を柱3本の先端ピンに瞬着 — 地平環が全てを囲む
✅ 動作確認: リング6回転でサロスが1周 (時計回り)・12回転で太陽玉が黄道を1周。玉が地平環の腕の下 (すき間2.8mm) をすり抜けるのを見届ける

Stage 4 「電動化」(任意)

部品: motor_cradle・28BYJ-48・ULN2003・ESP32・ローレットねじ M3×8 (×2)・皿小ねじ M3×8+ナット (×2) — ノブはそのまま (下面の溝がカップリングを兼ねる)
  1. (机の上で) 28BYJ-48 の耳を motor_cradle の下面に当て、皿小ねじを上から通してナットで留める — 頭は板に沈み、シャフトが板の大穴から上へ出る
  2. ノブを指で回して下面の溝を手前に向ける。モーター軸も指で回して、平らな面を左右に向けておく
  3. 揺りかごを手前から水平に差し込む — 足輪を越える所だけ少し (2.5mm) 持ち上げ、あとは板の上面を受け柱の下端に沿わせて奥へ。モーター軸がノブの溝に入り、溝の奥で止まる
  4. ローレットねじ2本を下から指で締める (受け柱の下穴 d2.6 にねじが自分で溝を切る — 初回だけ固い)
  5. ESP32 + ULN2003 を本体の横に置いて配線し、esp32/meguru_drive/ を書き込む (secrets.h は example から)
手回しに戻す時: ローレットねじ2本を抜き、揺りかごを手前へ引き出すだけ。ノブも上の機械も触らない (床まで2.6mm しかないので、下へは抜かない)
✅ 動作確認: lunar モードで1朔望月=リング1回転をリアルタイム刻み (約12359 steps・206.4秒/step — 遊星段の連成込み)。放っておくだけで月も年も食も歳差も、正しい速さで巡り続ける

困った時 (当たり調整早見)

症状処方
ターンテーブルがガタつく浅皿・滑り座に紙シム
天球リングが傾き方向に落ちる滑り座 (az20) の座面に紙シム
提灯まわりが渋い歯先を軽くヤスリで篩う (設計上の残差は最大0.3mm³まで — v0.7.1)
地下輪列が滑る/飛ぶ吊りスタッド接着前に軸間シムで詰め
圧入が入らないピンバイスで穴さらい (光造形の収縮はロット依存)
モーター軸がノブの溝に入らないノブの溝を手前へ、モーター軸の平らな面を左右へ向け直す。それでもきつければ溝の壁を軽くヤスリで
ローレットねじが固すぎるM3 タップで受け柱の下穴にねじを切ってから締める (樹脂を割らないため)
